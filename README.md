# Cube Cryptic

A mobile-first 3D cryptic crossword puzzle game. This repository starts from the latest confirmed source milestone: **Milestone 1 – Reliability (2 November 2026)**.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required for this current HTML version.

For a more reliable local server, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## The game

`index.html` is the game: black-square cryptic crosswords, six faces per cube, a hint-token ladder that grows the grid size. Puzzle data lives in `tools/mini_campaign.json` and `index.html` is generated from it.

Old note: (mixed word lengths, tap-to-type grid, on-screen keyboard). Face data lives in `tools/mini_face.json`; run `python tools/build_mini.py` to rebuild `index.html` and `python tools/validate_mini.py` to check that every clue's wordplay produces its answer.

## Development rules

- Preserve working gameplay and existing save compatibility.
- Make changes on feature branches; do not commit untested work directly to `main`.
- Run the validation workflow before merging.
- Do not add analytics until event names, consent/privacy behavior, and release requirements are reviewed.

## Run, install and deploy
- Play: open `index.html` in a browser, or serve the folder (`python -m http.server`) to test install/offline.
- Offline/install: `manifest.json`, `sw.js` and the icons make it installable (serve over https or localhost). `sw.js` is generated by `tools/build_mini.py` and versions its cache from the content of `index.html`.
- Hosting: `.github/workflows/pages.yml` publishes to GitHub Pages on push to `main` (enable Pages > Source: GitHub Actions in repo settings). This workflow has not been run yet.
- Edit content in `tools/mini_campaign.json`, then `python tools/build_mini.py && python tools/validate_mini.py`.
